## Appendix B: comparing a partial render with the existing file

Run it with `audio/.venv-casting/bin/python` (it has PyAV and numpy). Arguments: the test file, the existing file, and the first frame of the test range in the existing file.

```python
import sys, math, av, numpy as np
test, ref, first = sys.argv[1], sys.argv[2], int(sys.argv[3])
def frames(p, start=0, n=None):
    out = []
    with av.open(p) as c:
        for i, fr in enumerate(c.decode(c.streams.video[0])):
            if i >= start: out.append(fr.to_ndarray(format='rgb24').astype(float))
            if n and len(out) >= n: break
    return out
t = frames(test); r = frames(ref, first, len(t))
ps = [99 if (m := np.mean((a - b) ** 2)) == 0 else 10 * math.log10(255 ** 2 / m) for a, b in zip(t, r)]
print(f'{len(ps)} frames, PSNR mean {np.mean(ps):.1f} dB, min {min(ps):.1f} dB, under 35 dB: {sum(p < 35 for p in ps)}')
```
