- **Holds.** held drawings on 2s or longer; whole-pixel moves; no rotation or scaling of sprites (angles are drawn, flips of hourglasses are drawn states); windows open in 3 held steps.
- **Grid.** Every cut falls on a beat of the act's grid (act frame 0 = 12:31:00; set-pieces start on beats and run in whole bars). Sc 28's extra beat shifts the grid one beat after 16:21; sc 29-31 are re-balanced by <= 3 f each (<= 0.25 s from the script clock) to stay on it.

- **Rail.** RAIL text types on when it changes and persists across cuts until replaced; hidden on BLUEPRINT and full-screen cards. [V/K] items carry RECONSTRUCTED in the rail until upgraded.

- **Asset status.** NEW = build it · REUSE = exists (may need an overlay in a new file) · SALVAGE = port from the cut intro slot / an intro moment (never edit the original).
