# Ep1 · Act Four · POV changes, draft 3 → 3.1

*Staff writer, 2026-09-25. This is the production changelog for the POV table read: what changed in Act Four (sc 24–31) between script draft 3 and draft 3.1, line by line and shot by shot, and what that means for assets. The script is [script.md](../../script.md#act-four--the-blip-told-twice), and the reasons are in its [Revision log (POV table read)](../../script.md#revision-log-pov-table-read). The grammar is [pov-and-framing.md](../../../../bible/pov-and-framing.md), revised the same day (its §12).*

**Read this first.**
- **The board is two drafts behind.** [shotlist.md](history/shotlist.md) and [shots.json](history/shots.json) (board 1) are draft 2; draft 3 was never boarded. **Re-board straight from draft 3.1.** This file lists the deltas from draft 3 so nobody boards the draft-3 version from memory, or from the old worked example in pov-and-framing §7, which has been retired.
- **Tags.** `[M]` means a principal's waist-up rig and nothing else. A tighter plate of a room is `[W]`, and a close shot of a prop is a prop `[ECU]`. The shotlist legend's "A 'medium' is a tighter authored plate of the same room, never a scale" contradicts this; drop it at the re-board.
- **Lighting.** Every lighting note steps the room down. No face is relit unless the art director rules at W0 that Mas's portrait and `[CU]` are painted as materials for `resolve()`.
- Grid: 96 BPM, 1 beat = 0.625 s = 15 f, 1 bar = 2.5 s = 60 f.
