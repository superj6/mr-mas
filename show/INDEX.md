# MR. MAS · Writers' Room Index

The table of contents for the whole room: every file, one line each, plus a reading order and the status of each episode. Read-only research and design history lives in `_sources/` and is not indexed here.

- **As of:** 2026-09-25 (coordinator pass). Eps 1–9 follow real events through Sep 24, 2026; Eps 10–12 are speculative.
- **Rules of the room:** [README](README.md). Names come only from [bible/naming.md](bible/naming.md); hard exclusions are in [bible/guardrails.md](bible/guardrails.md); flashback placement is in [timeline/flashback-map.md](timeline/flashback-map.md).
- **Visual style:** **DECIDED 2026-09-25: pixel art primary** (adventure-game staging; glyph for foreshadowing; sparing motivated switches). See [bible/style-status.md](bible/style-status.md). Point of view: limited third person through Mas ([bible/pov-and-framing.md](bible/pov-and-framing.md), [bible/pov-clarification.md](bible/pov-clarification.md)).

## Episodes

Every episode folder holds the same seven files:

| File | What it is |
|---|---|
| `outline.md` | Date span, logline, A/B/C plots, cast, themes, camps roasted, THE PLAN, set-pieces, flashbacks, guardrails in play. |
| `beats.md` | The numbered beat sheet: each beat marked REAL (with date) or INVENTED, quotes tagged. |
| `flashbacks.md` | Each flashback: when, POV rim, era tier, length, trigger, what we see, transitions, guardrails. Must match the season flashback map. |
| `facts.md` | Everything real in the episode: events, on-screen quotes with original wording, figures, what is invented, what still needs verifying, what is excluded. |
| `gags.md` | This episode's step in each running gag, invented one-liners, visual gags and name cards for newcomers. |
| `intro-slot.md` | The episode's changing intro slots: cold-open line, bar 9 headlines, skyline and podium state, eggs, lint. |
| `open-questions.md` | Decisions still needed before lock, with defaults so writing can continue. |
