# MR. MAS — Writers' Room

The working foundation for the whole season. Every file is plain Markdown, meant to be edited by humans and agents.

**Start at [INDEX.md](INDEX.md)**: every file with a one-line description, a reading order, and the status of each episode.

```
show/
  bible/          overview, tone and rules, naming registry, guardrails, style decisions
  characters/     one file per character: real basis, exaggerated trope, design notes, voice, arc, appearances
  episodes/epNN/  outline.md · beats.md · flashbacks.md · facts.md · gags.md · intro-slot.md · open-questions.md
  timeline/       master-timeline.md (verified), flashback-map.md (which backstory lands where, and why)
  gags/           recurring-gags.md (setup → payoff tracker across episodes)
  world/          locations.md, orgs-and-products.md, props.md
  intro/          the 30s opening: spec, shot table, cue sheet, per-episode slot
  _sources/       research dossiers and design drafts these docs were built from (read-only history)
```

## Rules of the room
- **The broad plot follows real, verified events.** Invented filler must be obviously comedic.
  - Each episode's `facts.md` lists what's real (with dates and sources) and what's invented.
- **Satire is even-handed.** Every camp gets roasted, and every episode roasts at least three.
- **Hard exclusions:** see `bible/guardrails.md`. They cover private and family life, health, violence, deaths and wrongful-death suits, war casualties, and unadjudicated crimes.
- **Names come only from `bible/naming.md`.** Add new names there first.
- **Flashbacks are placed where they motivate the present-day plot.** See `timeline/flashback-map.md`.
