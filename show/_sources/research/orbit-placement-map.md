# Orbit placement map: where adjacent figures and AI/EA lore can ride existing scenes

> **Research note for the orbit-and-lore pass and the season revision, 2026-09-25.** Nothing here is canonical. No episode, bible, reel or character file was edited. This map answers one question: *where in the current season can a 5–20 s lore beat or a cameo ride a scene that already exists, without adding a scene?*
>
> **The showrunner's notes this map works under (binding):**
> - "also does thiel, palantir, flock, or similar have any precense? you don't have to cram every little reference in, but if you can where it is natural it would be nice to incorporate these related figures. we should also try to incorporate various ai/ea lore where reasonable but once again only where natural" · "another one maybe is leopold"
> - A **menu, not a quota** (the same rule as [world-stakes](../../bible/world-stakes.md) and [QUEUE](../../production/QUEUE-season-revision.md) §"Showrunner note on adjacent figures").
> - Fluid thriller drama, never clunky. No speculation labels. No episode announces its own climax.
>
> **Precedence:** [guardrails](../../bible/guardrails.md) > the POV contract ([pov-clarification](../../bible/pov-clarification.md)) > tone guide > [world-stakes](../../bible/world-stakes.md) (which already claims several of the same scenes; see §3) > this map. Each episode's `beats.md` still decides what happens.
>
> **Reference key:** `#n` = beat number in that episode's `beats.md` (line number given as `beats:L`). `sc n` = script scene (Eps 1–3 have scripts). `Wn.n` = a world-stakes insertion. Tags follow [guardrails §3](../../bible/guardrails.md#3-fact-handling-tags). **✓** = re-fetched this pass (sources in §6).
